# Migration to v0.2.0

## Summary

`.murmur/skips.md` is renamed to `.murmur/README.md`, and every mapped project gets a
`.murmur/manifest.json` recording the Murmur version, run history and everything
Murmur added. Projects mapped by v0.1.0 have no manifest, so the skill treats them as
a fresh install and the mapping prompt carries `skips.md` into `README.md`. These steps
cover a project that has a manifest but still has `skips.md`.

## Breaking changes

yes. `.murmur/skips.md` no longer exists. Anything that reads it, such as a script, a
link in project docs or a CI step, must read `.murmur/README.md` instead.

## Manual steps required

no

## Steps to migrate a project from the previous version

1. If `.murmur/skips.md` exists and `.murmur/README.md` does not, rename
   `.murmur/skips.md` to `.murmur/README.md`.
2. If both exist, append the content of `.murmur/skips.md` to `.murmur/README.md` under
   the heading `## Carried over from skips.md`, then delete `.murmur/skips.md`.
3. In the project's own files, outside `.murmur/`, replace every reference to
   `.murmur/skips.md` with `.murmur/README.md`.

## How to verify

1. `.murmur/skips.md` does not exist.
2. `.murmur/README.md` exists and contains everything that was in `.murmur/skips.md`.
3. Searching the project for `skips.md` finds no reference to `.murmur/skips.md`.

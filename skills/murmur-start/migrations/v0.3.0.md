# Migration to v0.3.0

## Summary

Murmur installs as portable Agent Skills, `murmur-start` and `murmur-update`, through
`install.sh`. The mapping prompt and migrations ship inside `murmur-start` instead of
being fetched from GitHub. The runner's `murmur validate` command checks load graphs,
and the prompt now states every rule it checks. A graph from an older version that
breaks one of them is rewritten by the mapping prompt's update run, so no separate
step is needed.

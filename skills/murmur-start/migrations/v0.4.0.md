# Migration to v0.4.0

## Summary

`{gen:...}` placeholders are limited to the generators the runner implements, listed in
the mapping prompt, and `murmur validate` also checks placeholders inside extract
JSONPaths. A graph that breaks either rule is rewritten by the mapping prompt's update
run, so no separate step is needed. The runner also gains the session walker and
`murmur simulate`, which change nothing in a project.

## Breaking changes

yes. A load graph from an older version that uses a `{gen:...}` name outside the list,
or a placeholder in an extract JSONPath that nothing extracts, fails `murmur validate`
until `murmur-start` runs in the project again.

## Manual steps required

no

None.

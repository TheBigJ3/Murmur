# Migration to v0.5.0

## Summary

Murmur now sends real traffic, with `murmur try` and `murmur swarm`. For that, a mapped
project gains a protected, dev-only `GET /internal/murmur/health` endpoint that both
commands check before sending anything, `.murmur/pool.example.json` showing the test
account fields, and `.murmur/pool.json` in its `.gitignore`. A graph can now read a
token from a response header and send it with top-level `headers`. The mapping prompt's
update run adds all of these, so no separate step is needed. To run the new commands,
create the pool accounts and fill in `.murmur/pool.json`, as `.murmur/README.md` explains.
